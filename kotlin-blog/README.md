# kotlin-blog

### Commands

```bash
ktlint --format
./gradlew kaptKotlin
./gradlew clean build
```

### Endpoints

| Verb | Path                                     |
|------|------------------------------------------|
| GET  | http://localhost:8080                    |
| GET  | http://localhost:8080/api/user/          |
| GET  | http://localhost:8080/api/user/{login}   |
| GET  | http://localhost:8080/api/article/       |
| GET  | http://localhost:8080/api/article/{slug} |
